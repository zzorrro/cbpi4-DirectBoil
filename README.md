# cbpi4-DirectPWMBoil

Плагин логики нагрева котла с прямым управлением PWM для CraftBeerPi 4.

## Описание

Простая и эффективная логика нагрева для этапа кипячения сусла. В отличие от PID или гистерезиса, которые постоянно "дергают" мощность, пытаясь удержать точную температуру, DirectPWMBoil использует всего два уровня мощности с чётким порогом перехода.

Это обеспечивает идеальное, спокойное и стабильное кипение без риска перелива через край — то, чего невозможно добиться классическими PID-алгоритмами.

## Как это работает

Логика предельно проста:
- Пока температура сусла **ниже порога перехода** → нагрев работает на **максимальной мощности** (быстрый нагрев до кипения)
- Как только температура **достигает порога перехода** → мощность плавно снижается до **рабочей** (спокойное, стабильное кипение)
- При выключении AutoMode → нагрев полностью отключается

## Возможности

- **Двухступенчатое управление мощностью**: максимальная мощность для быстрого нагрева и пониженная для стабильного кипения
- **Настраиваемый порог перехода**: температура, при которой происходит сброс мощности (например, 98°C)
- **Защита от спама команд**: мощность меняется только при фактическом переходе через порог, что продлевает жизнь SSR
- **Автоматическая поддержка °F**: если система переключена на Фаренгейт, порог перехода конвертируется автоматически
- **Безопасная остановка**: при выключении AutoMode или остановке рецепта нагрев гарантированно отключается
- **Оптимальная частота опроса**: проверка температуры каждые 2 секунды — достаточно для плавного PWM и не грузит Raspberry Pi

## Параметры логики

- **Power_Before** (Мощность до перехода, %): Мощность нагрева до достижения температуры перехода. Обычно 100%.
- **Transition_Temp** (Температура перехода, °C): Порог температуры, при достижении которого мощность снижается. Обычно 98°C (чуть ниже точки кипения, чтобы избежать бурного вскипания).
- **Power_After** (Мощность после перехода, %): Мощность нагрева после достижения температуры перехода для поддержания стабильного кипения. Обычно 50-70%.

## Настройка оборудования

### Настройка GPIOPWMActor (ТЭН)

В разделе **Hardware → Actors** создайте актор типа **GPIOPWMActor**:
- **GPIO**: номер пина Raspberry Pi, подключенного к SSR
- **Frequency**: **2 Гц** (рекомендуется для плавного нагрева без пульсаций и защиты SSR)
- **Inverted**: No (если SSR управляется прямым сигналом)

### Привязка к котлу

1. Зайдите в **Hardware → Kettles**
2. Выберите котел для кипячения (например, "Сусловарочный котел")
3. В поле **Sensor** выберите датчик температуры котла
4. В поле **Actor** (Heater) выберите ваш GPIOPWMActor
5. В поле **Logic** выберите **DirectPWMBoil**
6. Заполните параметры:
   - `Power_Before`: 100
   - `Transition_Temp`: 98
   - `Power_After`: 60
7. Нажмите **Save**
